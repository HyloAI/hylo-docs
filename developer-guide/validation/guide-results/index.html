    Capability results¶

    Recorded measurements previously embedded in the usage guides. These are observations under the conditions below, not expected output for a new run. The reproduction records link to the source scripts and full experiments; Research provides the analysis.

    Spatial memory¶

    On the MuJoCo table with targets visible for only the first 5 steps, composable.object_reach went from 0.00 to 0.75 success with spatial memory (300 pairs, p = 4e-68); per task, 0.99 on direct and push instructions and 0.27 on indirect ones ("the colour of a ripe tomato"), which the rule-based chooser cannot resolve with or without memory. With targets always visible, memory changed nothing (0.75 both ways). In a single traced episode, the recalled positions matched the true ones exactly and the agent switched from seen to remembered objects at step 5.

    uv run python examples/memory/01_spatial_memory_occlusion.py      # in the harness repository
uv run python examples/memory/02_observable_retrieval.py          # one episode's writes and retrievals

    Action memory¶

    Setting Result
    MuJoCo planar reach, revisited scenes 0.75 → 0.81 (p = 0.29)
    MuJoCo planar reach, new scenes 0.69 → 0.75 (p = 0.24)
    Six sessions on the same workcell, each extending the bank +4, +5, +7, +11, +1 points in sessions 2–6; pooled +5.6
    LIBERO-10, SmolVLA, bank from other start states 0.54 → 0.46
    LIBERO-10, same scenes, fixed t0 0.2 0.54 → 0.62 (p = 0.10)

    On MuJoCo the key is the policy's 8-dimensional state, so a neighbour from another scene is still informative. On LIBERO the key is pooled image features, which carry no information about the outcome on an unseen layout. Looser retrieval (k 10, floor 0.95) with a well-tuned policy made results worse on MuJoCo in a development run. Treat action memory as an experiment to measure on your task, not a default.

    uv run python examples/memory/03_action_memory_scene_recall.py    # in the harness repository
uv run python examples/memory/05_memory_across_sessions.py

    Lessons¶

    Two experience campaigns on MuJoCo planar reach wrote, read and credited a lesson book with llm.reflector on a local model. The effect of lessons on promotion has not been measured separately: it needs a language model in the loop and enough rounds to compare with and without lessons.

    Skill library¶

    On MuJoCo planar reach, a campaign proposed four noise-scale changes. One passed its gate (+0.42, p = 3e-12) and became a verified skill; three stayed proposed. The skills agent then applied it on fresh scenes, disjoint from every campaign split: 0.47 → 0.86 (200 pairs, p = 6e-19), with skill.applied in all 200 episodes.

    On LIBERO-10, the library built from two campaigns holds eight skills, none verified: the two most promising (+8 and +9 points on the gate) were not significant and are recorded as proposed.

    uv run python examples/memory/04_skill_library.py      # in the harness repository

    Action-memory diagnostics¶

    SmolVLA's velocity field pulls hard towards its own action: on LIBERO, a prior almost one standard deviation away moves the result about 40% of the way at t0 = 0.1 and hardly at all from t0 = 0.4. Useful guidance therefore lives at small t0.

    The noise-memory variant on unseen LIBERO start states scored 0.55 and 0.54 against a 0.54 baseline.

    Each decision emits memory.retrieval. From a recorded MuJoCo episode: five candidates above the floor, four kept, started at a fixed t0 of 0.3, with the source episode, step and similarity of each kept segment.
