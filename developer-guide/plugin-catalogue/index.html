    Plugin catalogue¶

    Every plugin installed in the development workspace, with the contract version it implements, how far it has been verified and its licences (hylo plugins). Maturity is declared by each package and was set from recorded runs:

    • implemented: run end to end on its target (a real simulator or robot), with recorded runs;
    • unverified: tests pass, but not yet run end to end on its intended target;
    • needs hardware: needs hardware that is not connected yet.

    95 implemented · 12 unverified · 1 needs-hardware
