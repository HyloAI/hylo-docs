    Example catalogue¶

    Every example config in hylo-bench and hylo-plugins, with the comment at its top. Run these commands from the workspace root, where bench/ and plugins/ are siblings. Config paths are relative to the working directory; runtimes and artifact ids resolve through the machine profile and store.

    For a guided first run, use the quickstart. Next steps matches tasks to guides and prerequisites.

    Experiments¶

    Expand an example for its description, command and configuration.

    libero10_critic¶

    SmolVLA on LIBERO-10: sample 4 chunks per decision, execute the one a learned chunk critic values most (hylo.agents.critic, model in hylo.instruments.critic). Train the critic first: uv run python -m hylo.learn.critic --runs runs/... --task-prefix libero/libero_10/ \ --image-camera agentview --out runs/critics/<name> and reference it by id (hylo store ref runs/critics/<name>). l10-v1 predates manifests and was adopted without a record of its training runs: it runs here, but the RSI gate refuses it in a candidate (unknown provenance).

    uv run hylo run bench/examples/configs/libero10_critic.yaml
    bench/examples/configs/libero10_critic.yaml 
    # SmolVLA on LIBERO-10: sample 4 chunks per decision, execute the one a learned chunk critic values most
# (hylo.agents.critic, model in hylo.instruments.critic). Train the critic first:
#   uv run python -m hylo.learn.critic --runs runs/... --task-prefix libero/libero_10/ \
#       --image-camera agentview --out runs/critics/<name>
# and reference it by id (`hylo store ref runs/critics/<name>`). l10-v1 predates manifests and was adopted without
# a record of its training runs: it runs here, but the RSI gate refuses it in a candidate (unknown provenance).
schema_version: hylo.experiment/v0.1
name: libero10-critic
benchmark: {type: libero, split: search_val, params: {suite: libero_10, protocol: rsi, replicates: 1, gate_looks: 3}}
env:
  type: libero
  remote: {runtime: libero-sim}
agent:
  type: remote
  params:
    ref: lerobot.critic_steered
    runtime: lerobot
    params:
      repo_id: lerobot/smolvla_libero
      num_threads: 3
      steering: {n_samples: 4, selector: gripper_vote_medoid, execution_steps: 25, seed_noise: true}
      critic: {path: "artifact:l10-v1@7934d463d67ad242", beta: 0.5, within_vote: true}
trace: {record_privileged: true, image_every: 5}
workers: 12
output_dir: runs

    libero10_memory¶

    SmolVLA on LIBERO-10 steered by an action memory of its own verified successes (RFC-0003 M1): flow sampling starts from a retrieved prior at t0 in [t0_min, t0_max] instead of pure noise. Build the memory first (development splits only): envs/libero/.venv/bin/python -m hylo.policies.lerobot.memory_build --runs runs/<search runs> \ --splits search --out runs/memory/<name> then reference it by id: hylo store ref runs/memory/<name>

    uv run hylo run bench/examples/configs/libero10_memory.yaml
    bench/examples/configs/libero10_memory.yaml 
    # SmolVLA on LIBERO-10 steered by an action memory of its own verified successes (RFC-0003 M1):
# flow sampling starts from a retrieved prior at t0 in [t0_min, t0_max] instead of pure noise.
# Build the memory first (development splits only):
#   envs/libero/.venv/bin/python -m hylo.policies.lerobot.memory_build --runs runs/<search runs> \
#       --splits search --out runs/memory/<name>
# then reference it by id: `hylo store ref runs/memory/<name>`
schema_version: hylo.experiment/v0.1
name: libero10-memory
benchmark: {type: libero, split: search_val, params: {suite: libero_10, protocol: rsi, replicates: 1, gate_looks: 3}}
env:
  type: libero
  remote: {runtime: libero-sim}
agent:
  type: remote
  params:
    ref: lerobot.memory_steered
    runtime: lerobot
    params:
      repo_id: lerobot/smolvla_libero
      num_threads: 4
      steering: {n_samples: 1, seed_noise: true}
      memory: {type: action_bank, params: {path: "artifact:l10-search-v1@40a84dd1afab4a5c"}}
      memory_steer: {k: 10, same_task: true, sim_floor: 0.95, t0_min: 0.1, t0_max: 0.7}
    env: {TORCHDYNAMO_DISABLE: "1"}
trace: {record_privileged: true, image_every: 10}
workers: 24
output_dir: runs

    libero10_noise¶

    SmolVLA on LIBERO-10 with noise-space steering (RFC-0004 W3): the initial flow noise is biased towards the noise that produced similar successful chunks; the policy is unchanged. Build the bank first (search split only): envs/libero/.venv/bin/python -m hylo.policies.lerobot.memory_build --store noise --splits search \ --runs runs/<search runs> --out runs/memory/<name> then reference it by id: hylo store ref runs/memory/<name>

    libero10_planner¶

    LIBERO-10 with an LLM/VLM subgoal planner (qwen3.5) in front of the steered SmolVLA. CPU only.

    uv run hylo run bench/examples/configs/libero10_planner.yaml
    bench/examples/configs/libero10_planner.yaml 
    # LIBERO-10 with an LLM/VLM subgoal planner (qwen3.5) in front of the steered SmolVLA. CPU only.
schema_version: hylo.experiment/v0.1
name: libero10-planner
benchmark:
  type: libero
  split: validation
  params:
    suite: libero_10
    n_validation: 10
    n_heldout: 0
env:
  type: libero
  remote: {runtime: libero-sim}
agent:
  type: planner.subgoal
  params:
    inner:
      type: remote
      params:
        ref: lerobot.steered
        runtime: lerobot
        params:
          repo_id: lerobot/smolvla_libero
          num_threads: 4
          steering:
            n_samples: 1
            seed_noise: true
    planner:
      type: planner.llm
      params:
        model: qwen3.5:35b-a3b
        cache_dir: runs/llm-cache
        subgoal_max_steps: 260
    check_every: 1
trace:
  record_privileged: true
  image_every: 10
workers: 24
output_dir: runs

    libero10_steered¶

    SmolVLA on LIBERO-10 behind SteeredAgent (seeded noise, sample-and-select, runtime rules). CPU only. Simulator and policy each run out of process in this machine's libero-sim / lerobot runtimes (hylo profile show; bench's envs/libero/setup.sh builds the venv and registers both).

    uv run hylo run bench/examples/configs/libero10_steered.yaml
    bench/examples/configs/libero10_steered.yaml 
    # SmolVLA on LIBERO-10 behind SteeredAgent (seeded noise, sample-and-select, runtime rules). CPU only.
# Simulator and policy each run out of process in this machine's libero-sim / lerobot runtimes (hylo profile show;
# bench's envs/libero/setup.sh builds the venv and registers both).
schema_version: hylo.experiment/v0.1
name: libero10-steered
benchmark: {type: libero, split: validation, params: {suite: libero_10, n_validation: 10, n_heldout: 0}}
env:
  type: libero
  remote: {runtime: libero-sim}
agent:
  type: remote
  params:
    ref: lerobot.steered
    runtime: lerobot
    params: {repo_id: lerobot/smolvla_libero, num_threads: 4, steering: {n_samples: 1, seed_noise: true}}
trace: {record_privileged: true, image_every: 10}   # keep every 10th camera frame (a frame pair is ~400 KB)
workers: 24        # thread budget: 24 x (4 policy + 2 render) ~ 144 threads on 128 cores
output_dir: runs

    mujoco_aloha_handover¶

    Two ViperX arms at a table (mujoco/bimanual-v0, RFC-0006 part 3): hand a bar from the arm that can reach it to the arm that reaches the named zone, which puts it there. The privileged oracle (object poses from the simulator) is the upper bound for this task; tool-using agents run with cameras instead: env params {cameras: [overhead, front, left_wrist, right_wrist], segmentation: true} need MUJOCO_GL=egl or osmesa.

    uv run hylo run bench/examples/configs/mujoco_aloha_handover.yaml
    bench/examples/configs/mujoco_aloha_handover.yaml 
    # Two ViperX arms at a table (mujoco/bimanual-v0, RFC-0006 part 3): hand a bar from the arm that can reach it to the arm that reaches the named zone, which puts it there.
# The privileged oracle (object poses from the simulator) is the upper bound for this task; tool-using agents run
# with cameras instead: env params {cameras: [overhead, front, left_wrist, right_wrist], segmentation: true} need
# MUJOCO_GL=egl or osmesa.
schema_version: hylo.experiment/v0.1
name: mujoco-aloha-handover
benchmark: {type: mujoco/bimanual-v0, params: {tasks: [handover]}, split: validation}
env: {type: mujoco.aloha_table, params: {cameras: [], privileged_obs: true}}
agent: {type: oracle.aloha_table}
output_dir: runs
