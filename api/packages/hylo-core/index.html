    hylo-core¶

    Hylo core: contracts, kernel, safety shield, events, trace, registry, config, remote env protocol

    Repository hylo-harness, packages/hylo-core. Licence: Apache-2.0. Depends on: numpy>=1.24, pydantic>=2.7, pyyaml>=6, websockets>=13, msgpack>=1.0.
