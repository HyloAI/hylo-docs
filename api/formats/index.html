    Formats and schemas¶

    Repositories cooperate through versioned formats defined in hylo-core, never through each other's code. Each format carries its schema version; the JSON Schemas below are what hylo schema NAME prints.

    Format Version Defined in Used for
    Robot description hylo.robot/v0.1 hylo.core.robot arms, hands, cameras and action layout
    Scene description hylo.scene/v0.1 hylo.core.scene declarative task scenes and success predicates
    Experiment config hylo.experiment/v0.1 hylo.core.config what is measured: benchmark, env, agent, timing
    Execution profile hylo.profile/v0.1 hylo.core.profile where runtimes and the store are on one machine
    Trace events core.events.TRACE_SCHEMA hylo.core.events, core.trace every episode, step by step
    Artifact manifest hylo.artifact/v0.1 hylo.core.artifact a sealed, digest-pinned learned thing
    Store index hylo.store/v0.1 hylo.core.store run and artifact ids, references, tombstones
    Scorecard hylo.scorecard/v0.1 hylo.core.scorecard a protocol's result for one policy
    Active version hylo.active/v0.1 hylo.core.deployment what a policy server deploys
    Workcell API hylo.workcell/v0.1 hylo.core.remote.workcell control plane <-> workcell
    Plugin contracts hylo.<group>/v0.1 hylo.core.plugins what a plugin implements
    Wire codec msgpack-numpy hylo.core.remote.wire remote environments and agents
