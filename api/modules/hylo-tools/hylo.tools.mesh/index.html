    hylo.tools.mesh¶

    Package: hylo-tools · Core contracts

    mesh ¶

    mesh: image + mask -> object mesh (.glb and .obj).

    hylo tool mesh IMAGE MASK [--depth DEPTH.npz] [--backend auto|sam3d|depth] [--method carve|hull|relief]
               [--scale S] [--out DIR]

    Backends behind one interface: - sam3d: SAM 3D Objects (facebook/sam-3d-objects, gated). Used when the weights are accessible; while access is pending (403) auto says so and falls back. - depth (CPU fallback): metric depth (the depth tool, MoGe-2, unless a depth map is given) -> masked back-projection -> cleaned point cloud, back completed by reflection across the silhouette plane -> closed surface (frustum carving + marching cubes, or convex hull) with vertex colours, in metres in the camera frame (or world, with T_world_cam). scale corrects a known metric scale error of the depth (e.g. from a known object size or table distance).

    MASK: a (H, W) bool .npy, a PNG (white = object) or a masks.npz from segment (--instance picks one; default union).

    MODEL module-attribute ¶

    MODEL = 'SAM 3D Objects (facebook/sam-3d-objects) | fallback: MoGe-2 depth + frustum carving'

    LICENCE module-attribute ¶

    LICENCE = 'SAM License (gated) | fallback: MIT (MoGe-2), BSD-3 (scikit-image), Apache-2.0'

    mesh ¶

    mesh(image: Any, mask: Any, *, depth: Any = None, K: ndarray | None = None, backend: str = 'auto', method: str = 'carve', scale: float = 1.0, T_world_cam: ndarray | None = None, instance: int | None = None, depth_model: str = 'Ruicheng/moge-2-vitl-normal', **run_kw: Any) -> Mesh

    An object mesh from one image and the object's mask. depth: None (run the depth tool), a depth.Depth, a path to an .npz with depth and K, or an (H, W) array (then pass K).
