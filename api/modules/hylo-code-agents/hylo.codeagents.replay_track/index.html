    hylo.codeagents.replay_track¶

    Package: hylo-code-agents · Core contracts

    replay_track ¶

    Perception for replay-to-sim (RFC-0006 part 8): lift a recording to 3D, track objects, detect contact events, register the camera to the robot and retarget a human hand to a parallel gripper.

    Frames. Tracking runs in a "frame" F with +z up and the table at z = table_z: the replay world itself when the recording knows its camera pose (our episodes), otherwise the gravity-levelled camera frame (GeoCalib roll / pitch, refined by the RANSAC table normal) shifted so the table is at z = 0. register then finds the similarity (scale, yaw about +z, translation) from F to the robot's world by aligning the carried object's track with the TCP path while the gripper holds it (the constant hand-object offset is absorbed by the translation).

    Tracking (per object): a model point set from the first frame's mask; per frame the mask is propagated by projecting the model at the predicted pose (a box around it), keeping pixels that match the object's colour histogram (when it is discriminative), lie above the table and near the predicted surface, and are closer to this object than to any other; the pose is refined by trimmed ICP (translation + yaw by default, or full 6-DoF). A frame whose fit fails keeps the prediction and is marked lost.

    Events: closed-gripper intervals from the opening signal (hysteresis relative to the open level); grasp (with the object that moves in the interval), lift (2 cm above its rest height), release, place (at rest after the release). The same detector runs on the simulation, so recorded and simulated events compare like for like.

    anchor_grasps ¶

    anchor_grasps(tcp: ndarray, objects: dict[str, ndarray], events: list[dict[str, Any]], intervals: list[tuple[int, int]], ramp: int = 5) -> tuple[np.ndarray, list[dict[str, Any]]]

    Grasp-anchored retargeting: a hand's thumb-index midpoint is not where a parallel gripper must close on the object (a wrap grasp holds the object beside the fingertips), so during each grasp the TCP path is shifted by the offset that puts it on the object's centre at the grasp moment, blended in and out over ramp frames. The hand's motion during the grasp is kept.

    hand_scale(kp3d: ndarray, kp2d: ndarray, depth: ndarray, K: ndarray, valid: ndarray) -> dict[str, Any]

    Scale that makes the monocular depth agree with the hand's metric size (the hand model's palm, about 9 cm wrist to middle knuckle): ratio of palm bone lengths, hand model over depth back-projection.

    hand_keypoints_world ¶

    hand_keypoints_world(kp3d_cam: ndarray, kp2d: ndarray, valid: ndarray, depth: ndarray, K: ndarray, T_frame_cam: ndarray, smooth: int = 5) -> dict[str, np.ndarray]

    The 21 hand keypoints per frame in F: each frame's metric hand (camera frame) shifted so its wrist and knuckles sit on the (scaled) depth map, as hand_to_gripper places it; missing frames interpolated, then a moving average over smooth frames. Returns {"kp": (T, 21, 3), "valid": (T,) frames with a detection}.

    hand_to_gripper ¶

    hand_to_gripper(kp3d_cam: ndarray, kp2d: ndarray, valid: ndarray, depth: ndarray, K: ndarray, T_frame_cam: ndarray, max_opening: float = 0.12, smooth: int = 5) -> dict[str, np.ndarray]

    Retarget one hand to a parallel-gripper TCP in F: origin between thumb and index tips, closing axis thumb to index, approach from the wrist towards the tips; opening = thumb-index aperture / max_opening. The hand is placed in depth by the (scaled) depth map at the wrist and knuckles; missing frames are interpolated.
