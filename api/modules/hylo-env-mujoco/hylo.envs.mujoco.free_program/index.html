    hylo.envs.mujoco.free_program¶

    Package: hylo-env-mujoco · Core contracts

    free_program ¶

    Scene programs (hylo.freescene/v0.1): loading one Python file into a restricted namespace.

    A scene program is a Python file with top-level declarations and functions:

    ROBOT = "panda" | "aloha" | "g1"     INSTRUCTION = "..."     MAX_STEPS = 900     LABELS = {...}   (optional)
def build(scene): ...                 required: adds the task's things to scene.spec (free_model.SceneHandle)
def success(sim) -> bool: ...         required: judges the state (free_world.SimView)
def randomize(sim, rng): ...          optional: per-seed changes to the start (free_world.SimEdit)
def demo(sim): ...                    optional: a scripted proof with invisible hands (checkers only)
def targets(sim) -> {name: xyz}: ...  optional: points a robot hand must reach

    program_problems(source) lists what keeps a source from loading (imports other than math / numpy / mujoco, names or attributes starting with an underscore, file and code-loading calls, classes); SceneProgram(path) checks, runs the top level with a small set of builtins and exposes the declarations. The code agents check programs the same way before they reach an environment (hylo.codeagents.scene_free_check.validate_scene_program); this second check guards files written by hand. Neither is an OS-level jail: run untrusted programs in a container.
