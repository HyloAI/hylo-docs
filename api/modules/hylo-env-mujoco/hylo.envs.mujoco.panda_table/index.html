    hylo.envs.mujoco.panda_table¶

    Package: hylo-env-mujoco · Core contracts

    panda_table ¶

    MuJoCo Franka Panda at a table: the manipulation environment of RFC-0006 part 3 (mujoco.panda_table).

    The arm and its parallel hand are the MuJoCo Menagerie model (Apache-2.0, fetched at a pinned commit into the asset cache on first use, see assets.py); the table, the objects and the cameras are ours. One model holds a pool of objects (blocks, cylinders, plates, bowls, trays, a large box, zones, numbered buttons); each episode activates the ones its task needs and parks the rest inside the table, so the model never changes shape and snapshots are cheap.

    Control: joint-position targets at control_hz (20 Hz; 25 physics steps of 2 ms underneath). Action = 7 joint targets (rad) + 1 hand command in [0, 1] (0 closed, 1 open). Observation layout follows hylo.core.robot: q.arm, hand.arm (measured, command units), RGB-D images per camera, <cam>.seg with segmentation=True, and camera intrinsics and poses in extra["cameras"]. With privileged_obs=True the observation also carries object poses and the task goal in extra["privileged"] (for the oracle agent; a privileged run is never ranked with an unprivileged one because env params are part of the experiment digest).

    Rendering needs an OpenGL backend: MUJOCO_GL=egl, or on CPU MUJOCO_GL=osmesa PYOPENGL_PLATFORM=osmesa with LD_LIBRARY_PATH pointing at an OSMesa build (bench/scripts/install-osmesa-user.sh). cameras=[] needs none.

    build_model ¶

    Compile the scene with the Menagerie Panda attached at BASE_POS (names prefixed with PREFIX). mesh_detail "fast" draws the arm with simplified visual meshes (about 6x fewer triangles; collision geometry unchanged), "full" with the original ones.

    attach_panda ¶

    attach_panda(spec: Any, mesh_detail: str = 'fast') -> None

    Attach the Menagerie Panda (wrist camera, gravity compensation, finger pads, stiffer grip) to an MjSpec at BASE_POS, names prefixed with PREFIX (shared with mujoco.panda_scene).
