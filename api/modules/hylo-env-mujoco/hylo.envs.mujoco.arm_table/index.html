    hylo.envs.mujoco.arm_table¶

    Package: hylo-env-mujoco · Core contracts

    arm_table ¶

    Shared machinery of the table environments with several arms (mujoco.aloha_table, mujoco.g1_table).

    A subclass supplies the robot (an MjSpec it attaches to the scene, its arms as ArmIO records, its RobotSpec), its cameras and its object pool; this base runs everything else the same way for every robot:

    • one compiled model holds a pool of objects; an episode activates the ones its task needs (colour, size, mass) and parks the rest inside the table, so the model never changes shape and snapshots stay cheap;
    • control is joint-position targets per arm plus a hand command per arm, at control_hz;
    • observations follow hylo.core.robot: q.<arm>, hand.<arm> (measured, command units), RGB-D per camera, <cam>.seg with segmentation=True, camera intrinsics and poses in extra["cameras"], and with privileged_obs=True object poses and the goal in extra["privileged"] (oracles only);
    • snapshots carry the episode record and the full integration state.

    The task family (sampling and success predicates) is a module with sample_episode(params, rng) and evaluate(env), named by the subclass.
