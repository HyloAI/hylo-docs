# Reference

Look up a command, configuration field, tool, Python symbol or stored format. Start with a
[User Guide](../user-guide/index.md) for a complete workflow.

| You need | Reference |
|---|---|
| Command arguments and defaults | [CLI](../cli/index.md) |
| YAML fields, runtime settings or environment variables | [Configuration](configuration.md) |
| Stage fields, robot controls, goal checks or camera tools | [Worlds & tools](worlds.md) |
| Python classes, functions and plugin contracts | [Python API](../api/index.md) |
| Versioned records and JSON Schemas | [Data formats & schemas](../api/formats.md) |
| Available plugin names, implementations and declared maturity | [Plugin catalogue](../developer-guide/plugin-catalogue.md) |

The [Python API package index](../api/packages/index.md) lists every package and its modules.
[Developer interface notes](../developer-guide/interfaces.md) explain integration semantics;
[extension tutorials](../developer-guide/adding-a-policy.md) walk through an implementation.
For runnable configurations, use the [example catalogue](../getting-started/examples.md).
