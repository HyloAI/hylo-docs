# API Reference

The Python API of `hylo-core`: the contracts every plugin implements, the episode loop, configuration, and the formats
the repositories exchange. A plugin needs only these modules from Hylo.

!!! tip "Contracts are pydantic models or protocols"
    Data contracts (`EnvSpec`, `Observation`, `ActionChunk`, `ExperimentConfig`, ...) are frozen pydantic models:
    build them with keyword arguments, copy them with `model_copy(update=...)`, and get a JSON Schema with
    `model_json_schema()`, or for the main configs with `hylo schema NAME` (experiment, task, env-spec, agent-spec,
    candidate, memory-item, benchmark). Behavioural contracts (`Environment`, `Agent`, `ChunkPolicy`, `Guard`, ...) are
    `typing.Protocol`s: a plugin does not inherit from them, it has the methods.

Each page has a short hand-written intro. The rest is generated by mkdocstrings from the docstrings and type
annotations of the code checked out next to this repository. Names that start with an underscore are left out.

[Packages](packages/index.md) has one page per package of every repository, with its modules, classes and functions,
signatures included, and the plugins it registers. Depend on the core contracts; read the rest to understand, extend
or debug.
