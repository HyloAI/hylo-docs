# Next steps { #choose-your-next-task }

After the [quickstart](quickstart.md), choose one path. Each guide states its own model, runtime and data needs.

| You want to | Start here | What you need | You finish with |
|---|---|---|---|
| See the improvement loop | [First improvement](first-improvement.md) | CPU workspace | a promoted controller and its evidence |
| Create a simulation | [Create and run a world](../user-guide/worlds.md) | CPU workspace; rendering for images | a stage, simulated world and goal checks |
| Run your existing model | [Run policies](../user-guide/policies.md) | a compatible policy and environment | a recorded experiment |
| Write task logic | [Programs](../user-guide/developing-strategies.md) | robot assets and camera rendering | a tested task program |
| Let a model operate a robot | [Tool-calling agents](../user-guide/tool-agents.md) | rendering and a configured model endpoint | tool calls, receipts and a task verdict |
| Develop and reuse a program skill | [Program skills](../user-guide/research-and-skills.md) | a model endpoint, rendering and development cases | a candidate, and a reusable skill if it is promoted |
| Give an agent history or experience | [Use memory](../user-guide/using-memory.md) | a supported consuming agent | scoped recall or a frozen experience source |
| Compare implementations | [Benchmarking](../benchmarking/index.md) | a protocol and compatible agents | paired scorecards |
| Deploy an implementation | [Deployment](../user-guide/deployment.md) | serve; Studio for the operator UI | a policy server and workcell |
